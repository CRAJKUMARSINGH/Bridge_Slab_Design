Field rules
	•	Numeric output: expected.value must be a finite JSON number. absoluteTolerance is non-negative and uses the same unit as expected.value; relativeTolerance is a non-negative dimensionless fraction. Compare using abs(actual - expected) <= absoluteTolerance + relativeTolerance * abs(expected). Each field gets its own values, approved by an engineer; never use a blanket tolerance.
	•	Exact output: for status, governing-case labels, or other categories, use comparison.kind = exact and compare the value exactly. Do not apply numeric tolerance to a pass/fail result.
	•	Provenance: sourceLocation must identify a stable workbook sheet/cell and visible label, or the schema can later add another explicit source type. baseline.artifact.sha256 pins the source artifact; approval.recordRef points to the review evidence. Record the recalculation engine because cached spreadsheet results can depend on it.
	•	Target and input: calculationRoute must name the path actually exercised; outputPath must be a stable data path, not UI text. Hash the exact tracked input fixture.
