1. design-engine.ts — Summary
Entry point: calculateCompleteDesign(input: ProjectInput) — exported as default.

Orchestration flow:

Calls calculateHydraulics(input) → Area-Velocity method (Manning's equation, Lacey scour, Molesworth afflux)
Calls calculatePierDesign(input, hydraulics) → 5 IRC load cases (Service, Construction, Flood, Seismic, ULS)
Calls calculateAbutmentDesign(input, hydraulics, 'TYPE1') → Rankine earth pressure, 5 load cases
Calls calculateAbutmentDesign(input, hydraulics, 'C1') → same model for cantilever abutment
Calls calculateDetailedEstimation(input, {hydraulics, pier, abutmentType1, abutmentC1}) → BOQ quantities and costs
Returns { input, hydraulics, pier, abutmentType1, abutmentC1, estimation }
