D — How to Wire Design Reports → Drawing Apps
Each of the 16 bridge design reports contains the exact parameter values needed by all the drawing apps above. Follow this 5-step workflow to go from a design report to a finished AutoCAD drawing.
5-Step Integration Workflow: Design Report → AutoCAD Drawing
1
Open the Design Report
Go to All Projects and open any of the 16 bridge design reports. The cover card shows all key parameters: span, HFL, pier cap, SBC, seismic zone.
2
Note the Abutment Type
Section C of each report specifies the IRC abutment type:
• Type 1 — Gravity (H ≤ 4.5 m) → use GAD_Gravity.dxf
• Type 2 — Cantilever (4.5–7.5 m) → GAD_Cantilever.dxf
• Type 3 — Counterfort (H > 7.5 m) → GAD_Counterfort.dxf
3
Download the Stability XLS
Each report's source-files panel (bottom of page) links to the Git LFS-stored Stability XLS. This contains the actual computed values. Download it for use as the Excel input to BridgeCanvas or Bridge_GAD_Yogendra_Borse.
4
Choose Your Drawing App
For DXF from Excel → BridgeCanvas or Bridge_GAD_Yogendra_Borse
For parameter form entry → BridgeGADdrafter (React UI)
For batch jobs → BridgeDraw
For catalogue + record → Dwg-Dxf-Record-Keeper
5
Generate + Download DXF
The app outputs an AutoCAD-compatible DXF. Open in AutoCAD, BricsCAD, or LibreCAD. File is saved into COMPONENT_DRAWINGS_SORTED/ in Dwg-Dxf-Record-Keeper for record keeping.
