API Documentation — IRC Bridge Design Suite

All REST endpoints exposed by the API server. Base URL: /api — all paths below are relative to this base. The server runs on Express 5 with JSON responses and SSE streaming for the sync endpoint.

GET /api/healthz
Health check endpoint. Returns server status. Use this to confirm the API server is running before making other requests.

Response

// HTTP 200 OK { "status": "ok" }
GET /api/reports/  Static file server
Serves all HTML design reports as static files. The index at /api/reports/ is the main project registry. Individual reports are at /api/reports/<filename>.html. Also serves shared assets (_shared.css, _nav.js, _print.css) and supporting pages (lfs-sync.html, irc-quick-reference.html, stats.html, api-docs.html).

GET /api/lfs-sync/repos
Returns all 18 GitHub repositories from the CRAJKUMARSINGH portfolio with their current sync state. State is persisted to sync-state.json in the workspace root and survives server restarts.

Response Schema

{ "repos": [ { "name": "Bridge_Slab_Design", "url": "https://github.com/CRAJKUMARSINGH/Bridge_Slab_Design", "label": "Bridge Slab Design", "desc": "IRC submersible & high-level slab bridge design — 100+ LFS assets", "primary": true, "exists": false, // whether local clone exists "status": "never", // "never" | "syncing" | "ok" | "error" "lastSync": null, // ISO 8601 timestamp or null "lastError": null, // error message string or null "fileCount": 0, // total files in clone "lfsFiles": 0, // files tracked by Git LFS "lastCommit":null // "hash date message" or null }, // ... 17 more repos ], "reposDir": "/home/runner/workspace/git-repos", "stateFile": "/home/runner/workspace/sync-state.json" }
GET /api/lfs-sync/status
Quick summary of sync state across all 18 repos. Lightweight alternative to /api/lfs-sync/repos when you only need aggregate counts.

Response Schema

{ "total": 18, "ok": 0, // repos with status "ok" "never": 18, // repos never synced "errors":0, // repos with last sync error "repos": [ { "name": "...", "status": "never", "lastSync": null }, ... ] }
POST /api/lfs-sync/pull  SSE Streaming
Triggers a full Git clone + git lfs pull for a single repository and streams real-time progress as Server-Sent Events (SSE). The response body is a stream — consume it with ReadableStream (Fetch API) or EventSource. The connection closes automatically when the done event is emitted.

Request Body

FieldTypeRequiredDescription
repoUrlstringREQUIREDFull GitHub URL — must match exactly one of the 18 registered repos
POST /api/lfs-sync/pull Content-Type: application/json { "repoUrl": "https://github.com/CRAJKUMARSINGH/Bridge_Slab_Design" }

SSE Event Stream

Response content-type is text/event-stream. Events arrive in order:
event: start
data: {"repo":"Bridge_Slab_Design","url":"..."} — sync job started
event: phase
data: {"n":1,"total":4,"label":"Initialising Git LFS"} — step progress (4 phases total)
event: cmd
data: {"line":"$ git clone --depth=1 ..."} — git command being executed
event: log
data: {"line":"Cloning into 'Bridge_Slab_Design'..."} — stdout/stderr line from git
event: warn
data: {"line":"LFS pull returned non-zero..."} — non-fatal warning
event: error
data: {"line":"FATAL: git clone exited with code 128"} — fatal error
event: done
data: {"success":true,"fileCount":312,"lfsFiles":87,"lastCommit":"abc1234 2026-05-01 ..."} — stream ends after this event

Error Response (non-SSE)

// HTTP 400 — unknown or unregistered repo URL { "error": "Unknown repo", "available": [ "https://github.com/CRAJKUMARSINGH/Bridge_Slab_Design", /* 17 more */ ] }

JavaScript Usage Example

// Consume SSE from a POST endpoint using Fetch + ReadableStream const resp = await fetch('/api/lfs-sync/pull', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ repoUrl: 'https://github.com/CRAJKUMARSINGH/Bridge_Slab_Design' }) }); const reader = resp.body.getReader(); const decoder = new TextDecoder(); let buf = ''; while (true) { const { value, done } = await reader.read(); if (done) break; buf += decoder.decode(value, { stream: true }); for (const block of buf.split('\n\n')) { const dataLine = block.split('\n').find(l => l.startsWith('data: ')); if (dataLine) { const event = JSON.parse(dataLine.slice(6)); console.log(event); } } buf = buf.split('\n\n').pop(); }
