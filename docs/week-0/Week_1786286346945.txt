What the code does

classify_cells.py (openpyxl, two passes: data_only=False for formulas + data_only=True for cached values) walks every cell and classifies it using explicit rules:

Variables ΓÇö hard-coded numbers with a label, no formula precedents of their own (roots of the dependency graph), that feed other formulas. Signals: sheet name contains input/param/variable, label contains span/length/width/depth/thickness/strength/load/number of, label says chosen/selected/adopted/provided (engineer decisions), or the cell has an Excel defined name (SpanL, steelgrade_fy).

Coefficients ΓÇö fixed factors, material properties, code limits, and numeric literals embedded inside formulas (8, 2, 1000, 384, 1000000ΓÇª ΓÇö flagged with location so you can promote real constants like 8 in M = wL┬▓/8 to named cells). Signals: sheet name contains factor/coeff/limit/table, label contains factor/gamma/modulus/density/unit weight/coefficient/capacity.

Constraints ΓÇö any formula that is an inequality or design check: IF(..., utilisation ratios, and their governing combinations (MAX). Each constraint is also emitted in standard optimisation form g(x) Γëñ 0 with a current-feasibility flag.

Ambiguous ΓÇö anything the rules can't decide at ΓëÑ0.7 confidence is NOT guessed; it's listed for you to confirm.

Confirmation happens three ways:
- --confirm ΓÇö interactive terminal prompts: v variable / c coefficient / k constraint / s skip / Enter keeps the guess
- --answers my_answers.json ΓÇö batch-preload your decisions so you only answer once ({"overrides": {"Calc!B13": "coefficient"}, "skip": []})
- the script never silently assumes ΓÇö low-confidence cells always appear on screen and in registry.json marked "ambiguous"
