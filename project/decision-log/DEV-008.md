# DEV-008 — Factored load coefficient: 1.5 applied to both dead and live load

- Opened: 2026-10-26
- Status: OPEN (owner W03, closing week W03)
- Source of truth: docs/week-0/coefficients.json → Factors!B3 = 1.35 (γ_G), Factors!B4 = 1.5 (γ_Q)
- Observed: client/src/report-engine/lib/slabCalc.ts line: `const w = 1.5 * (totalDL + totalLL)`

## Evidence
- The workbook records γ_G = 1.35 for self-weight and γ_Q = 1.5 for live load (IS 456:2000 Table 18 / IRC:6 limit-state approach)
- slabCalc.ts applies a single 1.5 factor to the combined DL+LL
- This over-factors dead load by 1.5/1.35 ≈ 11%
- OR: the design uses working stress method (WSD), where a single factor of 1.5 is an FOS, not a partial factor

## IRC/IS Reference
- IS 456:2000 Table 18: γ_DL = 1.35 (unfavourable), γ_LL = 1.5 (unfavourable) for limit-state design
- IS 456:2000 WSD (Annex B): overall FOS on loads = 1.5 is standard practice
- The distinction matters: if the slab is designed by WSD (which IRC:21 uses), 1.5 on the combined load is correct
