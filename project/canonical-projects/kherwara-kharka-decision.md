# Kherwara / Kharka project identity decision

## Status: OPEN

The attached evidence uses both `KHERWARA` and `KHARKA` strings. The plans
explicitly require this to be resolved before a project is called canonical.
This workspace therefore uses `KHERWARA` only as the key for the attached Week 0
demo parity fixture, not as proof that the two names identify one approved
project.

## Provisional use

- `KHERWARA` is the golden-fixture key.
- The fixture is illustrative and reproduces the attached demo workbook
  registry.
- It must not be presented as the authoritative 25-sheet production workbook.

## Required adjudication

An engineering owner must confirm whether the names identify one project or
separate sources, then select the authoritative workbook revision, report set,
drawing set, and applicable design code.
